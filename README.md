# Strategy Pattern

## Завдання

У рамках лабораторної роботи з теми **Стратегія (Strategy Pattern)** було реалізовано новий тип HTML-елементу `Image`, який динамічно підключає стратегію завантаження зображень залежно від типу переданого шляху (`href`):

- Якщо `href` починається з `http://` або `https://`, то зображення завантажується як із мережі.
- В іншому випадку зображення вважається локальним і завантажується з файлової системи.

Це реалізовано відповідно до патерну **Стратегія**, де об'єкт сам вибирає відповідну поведінку (конкретну стратегію) в рантаймі.

## Структура

- `IImageLoader` — інтерфейс для стратегії завантаження зображень.
- `FileImageLoader` — реалізація стратегії для локального завантаження.
- `NetworkImageLoader` — реалізація стратегії для завантаження з мережі.
- `LightImageNode` — HTML елемент типу `<img>`, який делегує завантаження обраній стратегії.
- `Program.cs` — демонстрація роботи з різними типами `href`.

## Патерн Стратегія

Переваги реалізації:

- Відділення алгоритму завантаження зображення від самого HTML-елементу.
- Можливість розширення — легко додати інші типи стратегій (наприклад, завантаження з кешу, CDN тощо).
- Гнучкість та відповідність принципам SOLID (зокрема, відкритість/закритість).
