# Спостерігач (Observer)

## Опис завдання

У цьому завданні до структури LightHTML було додано підтримку патерну **Спостерігач (Observer)**. Кожен HTML-елемент може мати підписників на різні події, такі як `click`, `mouseover`, `keydown`, тощо. При виклику певної події спрацьовують всі обробники, які були на неї підписані.

## Реалізація

### Основні компоненти:

- **IEventListener** — інтерфейс, який описує метод `HandleEvent(string eventType)` для обробки події.
- **ConcreteEventListener** — конкретна реалізація IEventListener, що реагує на подію повідомленням в консоль.
- **LightElementNode** — модифікований клас HTML-елемента, який:
  - має словник `eventListeners`, де ключ — тип події, значення — список обробників;
  - надає метод `AddEventListener(string eventType, IEventListener listener)` для додавання слухача;
  - має метод `TriggerEvent(string eventType)`, який активує відповідну подію.

## Приклад використання

У методі `Main` демонструється підписка на подію `click` та виклик цієї події для кожного `li`-елемента

## Висновок

Це завдання демонструє реалізацію патерну **Спостерігач**, де HTML-елементи можуть мати реакцію на події, що є основою інтерактивної поведінки в DOM-подібних структурах
